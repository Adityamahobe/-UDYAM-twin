# Datasets in this repository

Every dataset UDYAM-TWIN trains on or is evaluated with, where it comes from, and the terms it was published under.
**Simulation data is labelled as such everywhere it is used.** If you are the owner of one of these datasets and
want it removed from this repository, open an issue and it will be taken out.

| Dataset | Where | In the repo | Used for |
|---|---|---|---|
| AI4I 2020 Predictive Maintenance | `ml/data/ai4i2020.csv` | ✅ 0.5 MB | failure-risk Random Forest (`ml/train_ai4i.py`), REPLAY mode |
| UDYAM-SIM v1 (ours, synthetic) | `ml/data/udyam_sim_v1_*` | ✅ 26 MB | fault diagnosis model for the Advisor (`ml/train_sim.py`) |
| CWRU bearing recordings | `ml/vibration/data/cwru/raw/` | ✅ 40 `.mat` files, 140 MB | bearing-fault classifier (`ml/vibration/train.py`) |
| NASA C-MAPSS turbofan | `ml/data/cmapss/CMAPSSData.zip` | ✅ 12.4 MB zip | turbofan RUL research module (`ml/cmapss.py`) |
| IMS bearing run-to-failure: features | `ml/vibration/data/ims/features.csv` | ✅ 5.7 MB | ISO 20816-3 zone validation, early warning (`ml/vibration/train_ims.py`) |
| IMS bearing run-to-failure: raw | `ml/vibration/data/ims/IMS.zip` | ❌ 1.06 GB, above GitHub's 100 MB file limit | only needed to recompute the features |

## Sources, licences and how to cite

### AI4I 2020 Predictive Maintenance Dataset
- Source: UCI Machine Learning Repository, dataset 601, https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
- Licence: **Creative Commons Attribution 4.0 (CC BY 4.0)**: sharing and adaptation allowed with credit.
- Cite: S. Matzka, "AI4I 2020 Predictive Maintenance Dataset", UCI Machine Learning Repository, 2020.
- A synthetic dataset modelled on real milling-machine data (10,000 rows). `ml/ai4i.py` checks its SHA-256 before use.

### UDYAM-SIM v1
- Created by this project with `python -m tools.generate_dataset` (seed 2026): 440 randomised runs of the UDYAM-TWIN
  virtual factory. **Synthetic data from our own simulator**, described in [`ml/data/UDYAM_SIM_DATASET.md`](ml/data/UDYAM_SIM_DATASET.md).
- Licence: the same as the rest of this repository. There is no LICENSE file yet, which by default means all rights
  reserved by the authors; add a licence if others should reuse it.

### CWRU Bearing Data Center
- Source: Case Western Reserve University Bearing Data Center, https://engineering.case.edu/bearingdatacenter
  (12 kHz drive-end fault files and the 48 kHz normal baseline; file numbers 97, 98, 99, 100 … 237).
- Licence: published for free download for research; the site states no explicit licence for redistribution.
  Credit the Case Western Reserve University Bearing Data Center when you use it.
- Conversion and caveats (units assumed g, sampling rates, one lab rig): [`ml/vibration/README.md`](ml/vibration/README.md).

### NASA C-MAPSS (CMAPSS Jet Engine Simulated Data)
- Source: NASA Prognostics Data Repository, https://data.nasa.gov/dataset/cmapss-jet-engine-simulated-data
  (`CMAPSSData.zip`, 12,425,978 bytes, committed unchanged; `ml/cmapss.py` reads it directly).
- Licence: the NASA page says "License not specified". Data published by NASA's Prognostics Center of Excellence for
  public research use.
- Cite: A. Saxena, K. Goebel, D. Simon, N. Eklund, "Damage Propagation Modeling for Aircraft Engine Run-to-Failure
  Simulation", Proc. 1st International Conference on Prognostics and Health Management (PHM08), Denver, 2008.
- Simulated turbofan engines; kept separate from the CNC machines. Details: [`docs/CMAPSS.md`](docs/CMAPSS.md).

### IMS bearing data (features only)
- Source: NASA Prognostics Data Repository, "IMS Bearings", https://data.nasa.gov/dataset/ims-bearings (`IMS.zip`,
  1,061,902,801 bytes). Data generated by the NSF I/UCR Center for Intelligent Maintenance Systems (IMS), University of
  Cincinnati, with support from Rexnord Corp.
- Licence: the NASA page says "other-license-specified" without naming the terms.
- Cite: H. Qiu, J. Lee, J. Lin, "Wavelet Filter-based Weak Signature Detection Method and its Application on Roller
  Bearing Prognostics", Journal of Sound and Vibration 289 (2006) 1066–1090.
- **Only derived features are committed** (velocity RMS, acceleration RMS, peak, crest factor, kurtosis, dominant
  frequency, displacement and the ISO 20816-3 zone for every bearing and one-second snapshot), not the raw signals.
  To recompute them, download `IMS.zip` from the link above into `ml/vibration/data/ims/` and run
  `python -m ml.vibration.datasets.ims --zip ml/vibration/data/ims/IMS.zip --out ml/vibration/data/ims`.
  Details: [`ml/vibration/README.md`](ml/vibration/README.md).

### Synthetic datasets (dashboard generator) — SYNTHETIC DIGITAL TWIN DATA

Made with the **Synthetic Dataset Generator** panel or `POST /api/synthetic/generate` (`ml/synthetic.py`), saved in
`ml/data/synthetic/<dataset_id>/` (`windows.csv`, `episodes.csv`, `metadata.json`) and git-ignored.
Every row has `data_label = SYNTHETIC DIGITAL TWIN DATA`, and every download is named `SYNTHETIC_<id>_…`.
The metadata says `"synthetic": true, "real_machine_data": false`.

- **What it is:** each episode runs on its own simulation engine with a simulated clock, so the live dashboard
  and real telemetry are never touched. One CNC (VMC-01 or LATHE-01) gets Testing-mode parameters sampled from
  the requested ranges, within the same engineering limits as the Simulation Controls. It may also get one fault
  injected at a random time.
- **Features and labels:** the features are the UDYAM-SIM v1 window features (60 s windows every 10 s). The
  labels are the injected ground truth.
- **Reproducible:** the same config and seed give identical files. The checksums are in `metadata.json`.
- **Limits per dataset:** 1–200 episodes, 1–60 min each, at most 1,200 simulated minutes in total (about 30 s
  of CPU).
- **`over_limit_from_settings` (in `episodes.csv`):** marks episodes whose sampled settings alone put the machine
  over its temperature limit from the start. The VMC runs about 3.5 °C under its limit at default settings, so
  hot-ambient or low-cooling ranges produce many of these.
- **Licence:** generated by this project's simulator; same terms as the code.

A model trained only on these files has learned from the simulator, not from real machines.

## Not in the repository

- `ml/vibration/data/ims/IMS.zip` (1.06 GB): above GitHub's 100 MB per-file limit. Download it from NASA (link above)
  only if you want to recompute the IMS features.
- Unpacked or generated copies: `ml/data/cmapss/raw/` (unzipped C-MAPSS), `ml/vibration/data/cwru/dataset/`
  (rebuilt from the raw `.mat` files by `python -m ml.vibration.datasets.cwru`), and trained model files.
